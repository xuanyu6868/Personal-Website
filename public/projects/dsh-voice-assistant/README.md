# DSH Voice Assistant assets

The voice interface image is a static component preview from `dsh-voice-conversation/docs/voice-preview.html`, not a live Harness capture. The Mi Home console images are actual screenshots from `dsh-mijia-console/docs/images/`.

The device renderings are from `dsh-mijia-console/bundles/mijia-console/assets/`, where they are attributed to Xiaomi. They are used here to identify the devices.

The DeepSeek Harness mark uses the `FISH_LOGO_PATH` from `deepseek-ai/deepseek-harness/packages/client/ui-primitives/src/FishLogo.tsx`, with the path rendered in blue.

Project sources: https://github.com/xuanyu6868/dsh-voice-conversation and https://github.com/xuanyu6868/dsh-mijia-console.
